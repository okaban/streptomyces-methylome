# 単分子 call（正準・2026-10-15）

九ライブラリすべてを同一規則で抽出した per-read modification call。

入力: `methyl/260102_M145/analysis/*_mapped.bam`（2026-02-24 マージ、追加フローセル込み）
コマンド: `modkit extract calls --include-bed aagcccg_targets.bed --no-filtering --force`

## 抽出対象

AAGCCCG の **5 オフセット（0, 1, 3, 4, 5）を両鎖**、計 **6,670 位置**
（1,334 インスタンス × 5 オフセット）。

- オフセット 0, 1 = 1 番目・2 番目のアデニン（本文の position 1 / position 2）
- オフセット 4 = 正準の 4mC 位置（本文の position 5）
- オフセット 3, 5 = 旧 `fast_comod.py` が 4mC 位置として使っていた 2 箇所。
  正準センサスはオフセット 4 を使うが、旧解析との照合のため抽出には含めてある。

**下流の共修飾解析はオフセット 0 と 4 の 2 箇所のみを使う**（6mA = position 1、4mC = position 5）。

## 旧版との関係

旧 `65_per_read_comod/*_modonly.tsv` を置き換える。旧版は 1-1 のみ 824 万行・
他 8 本 25〜185 万行という不均一があり、抽出日も 1-1 だけ 2 日ずれていた。

## 閾値

適用していない（`--no-filtering`）。下流で指定すること。
**単分子の確率閾値は部位コールの閾値（A 0.6387 / C 0.9375）とは別物で、
従来の共修飾解析は一律 0.5 を使っている。** 0.5 と正準閾値では結果が大きく変わる
（T1 の OR が 1.257 対 0.962）ため、どちらを使ったかを必ず明記すること。

## 2026-10-15 の抽出事故（記録）

最初の抽出をオフセット 0,1,3,5 という誤った BED で実行し、オフセット 4（正準の 4mC 位置）
を取り落とした。BED を修正して再実行した際、**先行プロセスが生きたままファイルを削除・
再作成したため、1-1 の出力が一時的に不完全な状態で読まれた。**
その不完全なファイルから計算した T1 の値（39,430 ペア / OR 1.253）は誤りで、
プロセスを停止して取り直した後の値（**39,799 ペア / OR 1.257**）が正しい。
T2・T3 は影響を受けていない（両回とも完全一致）。
再抽出後はファイルサイズがバイト一致し、2 回の計算が完全一致することを確認済み。

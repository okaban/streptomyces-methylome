# 127 正準部位の再構築（2026-11-07）

目的: カバレッジ図（4mC と 6mA のどれだけがモチーフで説明できるか）を**正準の部位集合**で描く。
126 レーンのカバレッジ計算はスクリプトが保存されておらず部位定義を復元できなかったため、ここで作り直す。

規則（recompute_261015/corrected_census_261015.py と同一）:
  3 ライブラリを和集合インデックスで合算 → 真深度 (Nvalid+Nfail) >= 30 かつ level (Nmod/Nvalid) >= 0.5
  ＋ **参照塩基が修飾種と一致すること（refok）**
入力: recompute_261015/pileup_cache_261015/*.npz（code: 0=6mA, 1=4mC, 2=5mC）

再現確認: 4mC 2,909 / 2,869 / 2,840、6mA 1,947 / 2,150 / 2,308 — 補足表 S1c と 6 系列すべて一致。

注意: 自前で pileup の BED に awk をかける方法では再現しない。**refok 条件が必須**で、
これを落とすと 4mC が 1,666 / 2,476 / 1,179 と時点間でばらつく（2026-11-07 に実際に発生）。

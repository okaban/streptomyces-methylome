# 属全体 833 ゲノムにおける HAAGCCCG 枯渇検定 — 仮説 H8 / H15

## 結論（先に）

**HAAGCCCG は GAAGCCCG より強く避けられてはいない。むしろ逆である。**
配列組成の交絡を除いた本命の検定（最大次数マルコフ零仮説）では、現在の 6mA メチル化酵素の標的型
HAAGCCCG は属全体で **O/E 中央値 1.158（IQR 1.128–1.201、833/833 ゲノムで 1 超、Wilcoxon V=0, p=5.74e-138）** と、
期待よりわずかに**多い**。すなわち -1 位の G は期待より**少ない**（O/E 0.903、833/833 で 1 未満、同じ検定の裏返し）。
課題文の方向則「G が期待より多い = 制限標的だった証拠」に照らすと、**証拠は得られず、符号は逆向き**である。

4mC 対照（TGGCCGGC）でも同じ検定で O/E 中央値 1.095（820/833 で 1 超、V=1117, p=3.18e-136）と
同様に 1 を上回る。対応のある比較では 6mA 側の標的型のほうが 4mC 対照より**さらに**多い
（log2 差の中央値 +0.091、V=11991, p=7.7e-120）。
したがって、属全体で枯渇している AAGCCCG（O/E 中央値 0.703、610/833 = 73.2% が 0.75 未満）の枯渇は、
**メチル化される部分集合に局在していない**。孤児メチル化酵素仮説のうち「かつて制限標的だった」という部分は、
この検定では支持されない。

## 期待値の定義（必読）

| 項目 | 定義 |
|---|---|
| 計数単位 | 各アセンブリの全コンティグを 1 個の `N` で連結。`N` は照合しないのでコンティグ境界を跨ぐ語は数えない |
| 鎖の扱い | **両鎖・鎖指向性**。前向き連結 F と逆相補 revcomp(F) の両方で各語を数え、和をとる。非回文語ではこれが相異なるゲノム座位の列挙になる |
| 回文 | コア 7-mer は AAGCCCG / GGCCGGC でいずれも非回文（revcomp = CGGGCTT / GCCGGCC）。補助的に数えた 6-mer GCCGGC のみ回文で、1 座位が鎖ごとに 2 回数えられる。-1 塩基は鎖ごとに異なるので鎖指向性の -1 内訳は定義可能だが、本報告の 4mC 対照は非回文の **GGCCGGC** を核に用いた |
| 重複出現 | GGC 接頭/接尾による自己重複があるため、先読み付き正規表現 `(?=(...))` で重複込みに計数 |
| (a) 単塩基期待 | 両鎖対称の塩基頻度（p_A=p_T=(n_A+n_T)/2N, p_C=p_G=(n_C+n_G)/2N）を用い、語 w について E = 2(N−L+1)·Π p。既存表 `motif_site_density_genuswide.csv` と同一規約（GCF_014648775.1 の AAGCCCG で count 1363 / O/E 0.822 を完全再現） |
| (b) 最大次数マルコフ期待（**本命**） | 8-mer w1..w8 に対する Karlin/Burge 最大次数（= 6 次）推定 E = N(w1..w7)·N(w2..w8)/N(w2..w7)。コア出現数 N(w2..w8) で割ると**期待割合 = N(w1..w7)/N(w2..w7)**、すなわち「ゲノム中の 6-mer AAGCCC がその塩基に先行される経験確率」になる。観測値は 8-mer O/E と恒等的に一致する |
| 検定 | ゲノムごとに O/E を出し、log2(O/E) に対し Wilcoxon 符号順位検定（帰無: O/E = 1、両側）。統計単位はゲノム 1 個（n=833、M145 は分布から除外して別途位置づけ） |
| モデルフリー補助 | AAGCCC 座位の 2×2 分割表（-1 ∈ {G,H} × +7 が G か否か）のオッズ比。期待値モデルを一切使わない |

## なぜ単塩基期待では逆の答えが出るのか

単塩基零仮説では -1 位の G は O/E 1.569（833/833 で 1 超、p=5.74e-138）、
標的型 H は O/E 0.681 と「強く避けられている」ように見える。これは**交絡による見かけである**。
AAGCCC の直前が G である確率は、AAGCCCG であるか否かに関係なくゲノム全体で中央値 0.626 であり、
単塩基期待 p_G = 0.359 の **1.74 倍**ある（図 b）。
つまり「-1 に G が来やすい」のは AAGCCC という 6-mer の近傍組成の性質であって、メチル化部位の性質ではない。
この交絡を除くと符号が反転する。課題文が指定したとおり (b) を本命として読むべきである。

モデルを使わない 2×2 オッズ比も同じ結論を与える: 標的型オッズ比の中央値 **1.286**（833/833 で 1 超、V=0, p=5.74e-138）。
AAGCCC 座位のうち、+7 が G（= 真の AAGCCCG）であるものの -1 G 率は中央値 0.626 → 0.563 に**下がる**。
4mC 対照のオッズ比は 1.113（820/833）。

## M145 の位置づけ

M145（NC_003888.3、8,667,507 bp、GC 72.12%）は 833 ゲノムパネルに**含まれない**（パネルの S. coelicolor 代表は
別株 GCF_008931305.1）。そのため M145 を同一パイプラインで別途処理し、833 の分布に対するパーセンタイルで示した。

| 指標 | M145 | 833 中央値 | M145 パーセンタイル |
|---|---|---|---|
| AAGCCCG のうち -1 = G の割合 | 0.5765（769/1,334 = 57.6%） | 0.5631 | 64 |
| -1 = G の O/E（単塩基） | 1.599 | 1.569 | 62 |
| -1 = G の O/E（マルコフ） | 0.881 | 0.903 | 22 |
| HAAGCCCG の O/E（マルコフ） | 1.224 | 1.158 | 84 |
| TGGCCGGC の O/E（マルコフ、対照） | 1.156 | 1.095 | 94 |
| AAGCCCG モチーフ O/E（単塩基） | 0.649 | 0.703 | 24 |

M145 は -1 = G 率が属内でやや高め（64 パーセンタイル）だが、交絡を除いた HAAGCCCG O/E は 1.224 で
属内 84 パーセンタイル、すなわち**属内で最も標的型が「多い」側**に位置する。M145 を外れ値として救済する余地はない。

## 属内での相関（交絡の確認）

- HAAGCCCG O/E（マルコフ）とゲノム GC 含量: Spearman ρ = 0.575（p=1.8e-74）。
  GC が高いほど標的型の超過が大きい。ただし最低 GC 十分位（GC 68.3–70.4%）でも中央値 1.123、83/83 が 1 超、
  最高十分位（73.1–74.8%）で 1.205、83/83 が 1 超。**GC は効果量を動かすが符号を反転させない**（図 d）。
- HAAGCCCG O/E vs GAAGCCCG O/E（単塩基 8-mer、制約なし）: ρ = 0.485（p=1.9e-50）。
  全 833/833 ゲノムが y = x の**下側**にあり（図 c）、H 中央値 0.474 vs G 中央値 1.096。
  これは単塩基零仮説の下では H のほうが稀だという意味だが、その差は上記のとおり組成で説明し尽くされる。
  マルコフ零仮説での H と G の O/E は構成上 ΣO = ΣE に縛られ機械的に反比例する（ρ = -0.897）ため、
  散布図には制約のない単塩基版を用いた。

## 限界

1. **この検定はコアの存在を条件づけている。** 問うているのは「AAGCCCG のうちメチル化される部分集合が
   選択的に避けられているか」であって、「AAGCCCG 全体が避けられているか」ではない。後者は別途真（O/E 0.703）。
   本結果はその枯渇の**局在**を否定するだけである。
2. **最大次数マルコフ期待は 6-mer AAGCCC の近傍組成を「正しい基準」として受け入れている。** もし制限圧が
   AAGCCC を含む近傍全体を再形成したなら、この零仮説は圧の一部を期待値に吸収してしまう。
   ただしその場合でも「H のほうが G より避けられている」という予測は残るはずで、観測はその逆である。
3. **4mC 対照は完全な陰性対照ではない。** TGGCCGGC も標的型が O/E 1.09 と超過しており、
   「標的型が期待より多い」のは 6mA 系に固有ではない。両系で同方向・同程度ということが、
   この超過が制限修飾史ではなく共通の配列文脈効果であることを示唆する。
4. **系統的非独立性は補正していない。** 833 ゲノムは種代表 1 株ずつだが、Streptomyces 属内の系統的相関は残る。
   有効標本数は 833 より小さく、p 値は楽観的である。ただし効果の向きが 833/833 で一致している点は
   系統補正では覆らない。
5. **GC との強い相関（ρ = 0.57）は未解明。** 効果量の GC 依存性の機序は本解析では決めていない。
6. 課題文の「GCCGGC の -1 が T のもの（= TGGCCGGC）」は字面上不整合（GCCGGC + T は TGCCGGC）。
   6mA 系（7-mer コア + -1 可変 → 8-mer）と対応させるため、4mC 対照のコアを 7-mer **GGCCGGC** とし
   -1 = T で TGGCCGGC を定義した。6-mer GCCGGC の -1 内訳も成果物表に併記してある。

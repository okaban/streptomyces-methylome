## 1. 支持された所見・判断待ちの所見

### F1. 6mA は遺伝子間領域に濃縮するが、「終結領域に特異的」とは言えない（判断待ち・先行解析と整合）

**事前登録した IH07/IH09 の予測（convergent が最高）は粗い比較では的中したが、
局所 GC の窓幅を狭めると終結特異性が消える。** 以下は下方修正後の報告である。

**指標の定義。** 分子 = 正典フィルタを通った 6mA 部位数。分母 = 同じ領域クラス内の**可測アデニン位置数**
（真深度 >= 30 かつ refok == 1、修飾の有無を問わない）。単位は 10⁵ 可測位置あたりの部位数。
領域クラスは promoter = 予測 TU の 5′ 上流 300 bp、tandem = 3′→5′、divergent = 5′–5′、
convergent = 3′–3′、gene body = 遺伝子内。

| 領域クラス | 可測位置 | 6mA/10⁵（T1/T2/T3） | 4mC/10⁵（T1/T2/T3） |
|---|---|---|---|
| gene body | 2,139,032 | 77.8 / 86.1 / 92.1 | 48.4 / 47.8 / 47.3 |
| promoter（TU 5′ −300） | 220,265 | 85.8 / 88.1 / 99.4 | 30.7 / 29.8 / 28.6 |
| tandem gap 3′→5′ | 24,414 | 102.4 / 114.7 / 110.6 | 24.5 / 24.5 / 26.1 |
| divergent gap 5′–5′ | 2,599 | 115.4 / 153.9 / 153.9 | 35.3 / 35.3 / 35.3 |
| convergent gap 3′–3′ | 28,825 | 225.5 / 277.5 / 294.9 | 32.3 / 30.1 / 31.2 |

#### 局所 GC の窓幅で結論が変わる

層別 Mantel–Haenszel（GC 十分位 × 真深度五分位）を、GC の窓幅を変えて 2 通り走らせた:

| 比較 | GC ±250 bp | GC ±25 bp | 3 時点生存 |
|---|---|---|---|
| convergent vs gene body（6mA） | OR 2.768 / 3.135 / 3.130 | **OR 2.313 [1.80,2.97] / 2.586 [2.06,3.24] / 2.571 [2.07,3.20]** | **する**（q = 2.1×10⁻¹¹ / T2・T3 は p がアンダーフロー） |
| convergent vs 他の遺伝子間すべて（6mA） | OR 1.771 / 2.014 / 2.024 | **OR 1.244 [0.94,1.65] / 1.487 [1.14,1.93] / 1.436 [1.12,1.85]** | **しない**（T1 p = 0.128、CI が 1 を含む） |
| convergent vs gene body（4mC） | OR 0.681 / 0.665 / 0.692 | — | しない（q = 0.085–0.112） |

遺伝子間位置だけを母集団にしたロジスティック回帰でも同じ向きである:
GC ±250 bp で convergent OR 1.788 / 2.067 / 2.079（p = 6.6×10⁻⁵ 〜 2.0×10⁻⁸）だが、
GC ±25 bp にすると 1.265 / 1.485 / 1.467（p = 0.106 / 0.0032 / 0.0031）。
**遺伝子間間隙長（log₁₀）は交絡していない**（OR 0.929–1.196、p = 0.25–0.91、投入しても convergent の OR はほぼ動かない）。
また GC ±25 bp では divergent gap の OR が 1.160 / 1.531 / 1.470 と convergent とほぼ同水準になり、
「終結領域が二つ向かい合う場所だから」という読み方は支持されない。

#### 先行解析との突き合わせ（これが下方修正の根拠）

`15_paper_figures/scripts/recompute_261015/bio261016/`（2026-10-16）が、未帰属 6mA を対象に
同じ仮説をすでに検定していた。`B1_gap_class_261016.tsv` の convergent は粗 OR 2.2148（p = 1.7×10⁻⁷）、
GC 層別 MH 1.1935、`B1_gap_logit_261016.tsv` の全項投入モデル（gc50 = ±25 bp、log_depth、
convergent、divergent、log_gaplen）で **OR 0.9357、p = 0.657** と帰無になっている。
本解析の GC ±25 bp 版（T1 OR 1.244–1.265）はこの先行値と整合する。
**当初 GC ±250 bp のみで層別して「終結領域への濃縮」を主要所見としたのは、
6mA のコール率が短距離の局所 GC に強く依存する（±20〜30 bp にピーク）ことを過小に統制していたためである。**

#### 残るもの

遺伝子間領域全体としての 6mA 濃縮（convergent vs gene body OR 2.31–2.59、狭い GC 窓でも 3 時点生存）は残る。
ただしこれは既知の所見の再確認であり、新規ではない: 未帰属 6mA について
「GC と深度で調整しても遺伝子間領域 OR 1.98（p = 3×10⁻¹⁶）」がすでに記録されている。
**4mC は同じ比較で帰無**（OR 0.665–0.692）なので、「遺伝子間への偏りは 6mA に固有」という
マーク間の非対称は言える。これは F3 のプロモーター解離と同じ向きの話である。

**判定: 判断待ち。** 「convergent（終結）領域に特異的」は否定。「遺伝子間に 6mA 固有の濃縮がある」は
支持されるが既報の再確認。図は窓幅依存性をそのまま示す形にした
（`figures/FigC_6mA_intergenic_enrichment.png`）。

### F2. AAGCCCG の 6mA 占有率は、モチーフがホスト遺伝子のセンス鎖にあるとき 3 倍以上高い

**指標の定義。** 分子 = 第 1 アデニン（A₁）が正典フィルタを通ったインスタンス数。
分母 = A₁ が可測なインスタンス数。遺伝子内インスタンスのみ。
`mod_sense` = モチーフの載る鎖がホスト遺伝子のセンス鎖（非鋳型鎖）と一致するか。

| 対象 | センス鎖 | アンチセンス鎖 | n（可測・遺伝子内） |
|---|---|---|---|
| AAGCCCG 6mA（A₁）T1/T2/T3 | 34.88 / 36.66 / 35.16% | 10.21 / 11.89 / 11.46% | 1,181 / 1,183 / 1,182 |
| AAGCCCG 4mC（C₄、**同一インスタンス**） | 78.62 / 75.00 / 74.96% | 77.02 / 74.31 / 73.25% | 同上 |
| TGGCCGGC 4mC | 89.75 / 89.68 / 88.67% | 91.51 / 91.86 / 90.86% | 1,986 / 1,988 / 1,988 |

ロジスティック回帰（統制項: 修飾鎖上の −6…−1 と +1…+3 の全 9 塩基をカテゴリ変数、コドン位相、
局所 GC ±250 bp、真深度の対数、core/arm、DNA 鎖（plus/minus）、複製鎖（leading/lagging）、
ホスト遺伝子の log₂(TPM+1)）:

- **AAGCCCG 6mA: OR 2.641 [1.41, 4.95] / 1.809 [0.99, 3.30] / 2.835 [1.57, 5.12]**、
  p = 0.0025 / 0.053 / 0.00055（T1/T2/T3）
- AAGCCCG 4mC（同一インスタンス、同一鎖、同一文脈）: OR 0.882 / 0.853 / 0.820、p = 0.29–0.51 → **帰無**
- TGGCCGGC 4mC: OR 0.825 / 0.777 / 0.800、p = 0.15–0.26 → **帰無**
- 複製鎖軸（modified strand = leading）: OR 1.387 / 1.318 / 1.438、p = 0.035–0.105 → ほぼ帰無
- DNA 鎖軸（plus/minus そのもの）: OR 0.887 / 1.051 / 1.148、p = 0.41–0.76 → 帰無
- ホスト遺伝子発現: OR 0.933 / 0.965 / 0.970、p = 0.094–0.43 → **帰無**（permissive と整合）

**転写共役ではない。** 発現四分位ごとの粗い OR は Q1（沈黙遺伝子）3.45–4.32、Q2 3.40–4.37、
Q3 3.56–5.08、Q4 7.23–8.53 で、**最低発現四分位でも同じ向きに存在する**。
センス鎖占有率は四分位を通じてほぼ一定（31.9–37.5%）で、Q4 で OR が上がるのは
アンチセンス側の占有率が 12–14% から 6–7% に下がるため。
`mod_sense × log TPM` の交互作用は帰無（p = 0.45 / 0.79 / 0.55）。
したがって「転写が修飾を呼ぶ」ではなく、遺伝子の向きに対するモチーフの向きそのものが効いている。

**重要な否定的対照（これを書かないと過大主張になる）。** ゲノム全体で HC 部位のセンス鎖比率を
可測位置の背景（約 51%）と比べると、6mA も 4mC も同じ程度に偏って見える
（6mA OR 1.665–1.834、4mC OR 1.841–1.854、いずれも p < 1 × 10⁻²⁸）。
しかしこれは**モチオフ自身の向きの偏り**で説明される: 遺伝子内 AAGCCCG インスタンスの 60.22%、
TGGCCGGC の 69.72% がセンス向きである。修飾レベルの偏りではない。
モチーフを固定した条件付き比較（上表）でのみ 6mA に差が出る。

**局所 GC の窓幅には頑健（F1 と対照的）。** F1 を下方修正させた ±25 bp の GC 統制に差し替えても
OR は 2.711 [1.44,5.09] / 1.825 [0.99,3.36] / 3.085 [1.68,5.65]（p = 0.0019 / 0.053 / 0.00026）で動かず、
±250 bp と ±25 bp の両方を同時に入れると 2.921 / 1.898 / 3.109（p = 0.0011 / 0.041 / 0.00025）で
T2 も p < 0.05 に入る。モチーフ配列が固定で隣接 9 塩基を個別に統制しているため、
窓幅の違いが寄与する余地が小さいことと整合する。

**3 時点生存。** 最も厳しいモデル（コドン位相込み・GC ±250 bp）では T2 の p = 0.053 で境界。
コドン位相を外した同じモデルでは T1 0.0029 / T2 0.0074 / T3 0.0013 で 3 時点とも p < 0.01。
**T2 は最厳モデルで境界と明記すべきで、「3 時点すべてで有意」と書いてはいけない。**

**未帰属 6mA でも同じ向き。** 遺伝子内の未帰属 6mA のセンス鎖比率は 61.40 / 62.11 / 59.64% で、
可測アデニン位置の背景 51.05 / 51.40 / 51.12% に対し OR 1.525 / 1.550 / 1.413（p = 1.7 × 10⁻¹³ 〜 6.5 × 10⁻¹⁶）。
ただしこれは文脈を固定していない比較なので、近縁文脈への偏り（既知、OR 2.17）と分離できていない。

図候補: `figures/FigD_6mA_gene_orientation.png`（この主張専用）。

### F3.（事後）プロモーター近傍で 2 つのマークの向きが分かれる — ただし T1 が境界

**事前登録のない事後所見であることを明示する。** IH01 の検証中に出たもので、予測を先に書いていない。

実験 TSS（Jeong 2016、category P/S かつ gene_id 付き 3,030 本）の −300..+50 を近傍と定義し、
分母を全可測位置（6mA 2,415,180 / 4mC 6,247,708 @T1、サンプリングなし）とすると:

| | 粗い OR（T1/T2/T3） | GC 十分位 × 深度五分位 層別 OR_MH | q（BH） |
|---|---|---|---|
| 4mC | 0.835 / 0.807 / 0.820 | **0.826 [0.72,0.95] / 0.796 [0.69,0.92] / 0.807 [0.70,0.93]** | 0.013 / 0.0081 / 0.0081 |
| 6mA | 0.774 / 0.801 / 0.804 | **1.157 [0.98,1.36] / 1.208 [1.03,1.41] / 1.201 [1.03,1.39]** | 0.083 / 0.019 / 0.019 |

粗い比較では両マークとも枯渇しており、原稿の記述と一致する。局所 GC と深度で層別すると
4mC は枯渇のまま、6mA は濃縮に反転する。6mA の GC 係数が +18.6〜19.0（0–1 スケール）と極端に大きく、
プロモーターが局所的に AT 寄りであること（原稿自身が補足図 10 で示している事実）が
粗い枯渇を作っているため。

レベル尺度（可測位置の平均修飾頻度）では、粗い差 −0.597 / −0.642 / −0.685 パーセントポイントが
GC・深度調整後に +0.028 / +0.061 / +0.028 pp（p = 0.43 / 0.093 / 0.46）となり消える。

AAGCCCG 帰属 6mA に限ると帰無（OR 0.953 / 1.367 / 1.219、近傍の可測位置 57–67 本で検出力が無い）。
効果は未帰属画分が担う（OR 1.309 / 1.284 / 1.372、q = 0.0094 / 0.0094 / 0.0010）。

**判断。** 4mC の枯渇は 3 時点で生存。6mA の濃縮は T2/T3 で生存、T1 は CI が 1 を含む（0.98–1.36）ので、
3 時点生存規則の下では**判断待ち**。原稿の「両修飾ともプロモーター近傍で枯渇」という記述とは
向きが食い違うが、原稿は 4mC を**部位密度**、生き残る 6mA 効果を**レベル**として区別して書いており、
本解析は部位呼び出し確率（レベル >= 0.5 の二値化）を見ている。**同じ量ではない。**
どちらが原稿の主張に対応するかは著者と査読者の判断事項であり、ここでは両方の数値を並べて報告する。

### F4. AAGCCCG インスタンスの所在（記述、配列可用性としてのみ）

1,334 インスタンスのうち **1,184 が遺伝子内（1,045 遺伝子に分布）、150 が遺伝子間**
（tandem 88 / divergent 42 / convergent 18 / 配列末端 2）。
GC 十分位でマッチさせた全遺伝子（n = 8,275）からの期待に対し:

| 注釈カテゴリ（product キーワード） | 観測 | GC マッチ期待 | 比 | q |
|---|---|---|---|---|
| hypothetical | 82 | 140.1 | 0.585 | 1.7 × 10⁻⁷ |
| regulator / sigma factor | 57 | 93.3 | 0.611 | 1.4 × 10⁻⁴ |
| transport / permease / ABC / efflux | 123 | 90.1 | 1.366 | 0.0013 |
| ribosome / tRNA / elongation factor | 32 | 19.6 | 1.633 | 0.016 |
| oxidoreductase 系 | 88 | 74.2 | 1.187 | 0.17 |
| secondary metabolism | 33 | 26.1 | 1.264 | 0.22 |
| kinase / two-component | 39 | 34.5 | 1.129 | 0.50 |
| membrane | 10 | 11.0 | 0.905 | 0.88 |

**これはモチーフがどこにあるかであって、修飾がどこにあるかではない。**
制御因子注釈の遺伝子で AAGCCCG 配列そのものが GC マッチ期待より少ない（比 0.61）という事実であり、
メチル化による制御回避の証拠ではない。この区別を落とすと、原稿が既に
「プロモーター近傍の見かけの欠損は認識配列の所在で説明される」として扱っている論法と衝突する。
注釈キーワードによる分類は粗く、`hypothetical` の枯渇は GC マッチの不完全さも疑われるので、
この表は**暫定**として扱う。

| IH18 | 同一インスタンスの 4mC+6mA 二重修飾がホスト発現に効く | **否定。** 二重修飾インスタンスのホスト遺伝子 vs 4mC のみのホストで log₂TPM 中央値 4.173 vs 4.260（T1）、4.081 vs 4.176（T2）、4.388 vs 4.202（T3）、q = 0.52、n = 231–251 vs 633–682 |

これら 9 件はいずれも permissive 命題（メチル化は転写を指示しない）と整合する。
**無理に有意にしていない。IH06 と IH12 は「帰無」ではなく「検出力不足」であることを明記する。**

## 4. 原稿の数値との関係

本解析では原稿の数値を一つも書き換えていない。原稿と突き合わせたのは 1 点だけである。

- 原稿（EN、R2 相当）: 4mC の「promoter-proximal な部位密度の欠損は GCCGGC 六量体の
  近傍での希少さで説明される」、生き残るのは「6mA の **level** のプロモーター近傍欠損（約 7 pp）」。
- 本解析（§F3）: 可測位置を分母にした**部位呼び出し確率**では、粗い比較で両マークとも枯渇（原稿と同方向）。
  GC・深度層別後は 4mC 枯渇のまま / 6mA 濃縮に反転。レベル尺度では GC・深度調整後に差が消える
  （+0.028〜+0.061 pp、p = 0.093–0.46）。
- **部位呼び出し確率とレベルは別の量であり、本解析の分母（全可測位置）は原稿の分母
  （GCCGGC インスタンス）とも異なる。** 原稿の「7 pp」を再現したとも反証したとも言えない。
  どちらの量で論じるかは著者の判断事項。本報告は両方を並べる。

## 6. 申告（データ範囲の縮小）

- **IH11 / IH14 / IH16 は未実施**（優先度 4–5、既存解析と重複の見込み）。IH17 は入力データが無く検証不能。
- 未帰属 6mA のセンス鎖比率の背景（§F2 末尾）は、可測位置 241 万本のうち **20 万本の無作為標本**で算出した。
  AAGCCCG と TGGCCGGC のモチーフ固定比較、および §F1・§F3 の層別解析はすべて**全可測位置**で、標本化していない。
- 領域クラス別のロジスティック回帰（`IH0x_region_logit.tsv`）は case–control 設計
  （全 HC 部位 + 可測位置 12 万本の標本）で、本文の結論に使っている層別 MH は全数。
- **局所 GC の統制は当初 ±250 bp の窓だけで行っており、F1 はこれで「終結領域への濃縮」として
  報告しかけた。** 先行解析（bio261016、2026-10-16）との突き合わせで窓幅依存に気づき、
  ±25 bp に差し替えて下方修正した。F2・F3 も ±25 bp で確認済み（F2 は不変、F3 は GC 十分位層別で実施）。
  本報告の所見はすべて「報告した窓幅での結論」であり、より狭い窓や別の組成指標で再度動く可能性は残る。
- TU モデルは**予測**であり実験的に決定した転写単位ではない。自前の発現相関で検証したが
  （TU 内 r = 0.934 vs TU 間 0.629）、予測モデルに依存する所見（IH01、F1 の promoter クラス）は
  その限りでの結論である。F1 の遺伝子対の向きの分類は TU 予測に依存せず、
  GFF の遺伝子座標と鎖のみから定義される。

# エピアレル構造の配列一致対照（2026-10-15）

分子内の 3 位置（AAGCCCG の position 1 / position 2 / position 5）の状態構造を、
同一ジオメトリ・同一リード深度の非モチーフ三つ組と比較した。

- `epi_excess_by_set_261015.csv` — インスタンスごとの観測 ΔH、並べ替え帰無、超過、p 値
- `epi_summary_261015.csv` — 集合ごとの要約
- `epi_expression_cv_261015.csv` — 遺伝子ごとの発現 CV（T1 の 3 複製）と判定

ΔH = H(3 位置が独立なら期待されるエントロピー) − H(観測されたエントロピー)。
超過 = 観測 ΔH − 周辺確率とリード深度を保存した 100 回の並べ替えの平均。
対照 = AAGCCCG / TGGCCGGC のいずれからも 60 bp 以上離れた (A,A,_,_,C) 三つ組 800 件。
入力は `111_perread_canonical_261015/calls/`（九本同一規則の抽出）。

補足図 15 が距離対照（分子間 10 bp 超）で同じ問題を扱っており、本解析は配列対照を足すもの。
両者とも「分子内の連関は実在するがエピアレルの規模には届かない」で一致する。

## 分母と対象（すべての数値に共通）
T1 プール（1-1,1-2,1-3）で参照塩基照合済み（+鎖 A / −鎖 T）・pre-filter 深度 >= 30・Nvalid > 0 の
非モチーフ参照アデニン **2,412,520 箇所**。うち pooled Nmod/Nvalid >= 0.5 が **1,531 部位**、
呼ばれなかった適格位置が **2,410,989 箇所**（ブリーフの「2,412,520 箇所」は適格総数であって
呼ばれなかった数ではない。本メモは 2,412,520 = 1,531 + 2,410,989 として扱う）。AAGCCCG の A0/A1（両鎖 2,660 位置）は除外。
比較はすべて「呼ばれた 対 同じ深度条件を満たしながら呼ばれなかった」。ランダム対照は使っていない。

## 結論（先に）
**「GC リッチな遺伝子間 DNA に偏った背景」以上のことが一つだけ言える。**
未帰属 6mA は、修飾鎖の読み枠で **3' 側に C 連続を持つ文脈**に濃縮しており、
これは同一 GC・同一窓の **G 連続では完全に平坦**で、局所 GC では説明できない。
C 連続は cognate 認識配列 AAGCCCG の 3' 半分（CCC）そのものであり、
5' 塩基の規則（H > G）も cognate と同方向で保たれている。
すなわち未帰属 6mA は乱雑な背景ではなく、**cognate モチーフの近縁文脈に沿った裾**である。

ただし**この観測は酵素説とナノポア塩基呼び出し説のどちらとも整合し、本データ単独では分離できない。**
分離には WGA/PCR 非メチル化対照または SC_RS17645 破壊株の再測定が要る（正典の既存 caveat と同じ壁）。
さらに効果量は cognate の 57 分の 1（最良近縁変異体 0.804 % 対 HAAGCCCG 45.84 %）で、
レベルも閾値直上に集中したまま（中央値 0.566）。『緩和された特異性』と呼べる水準ではない。

## 測った中身

### 支持された（3 件）
1. **3' C 連続の用量反応**（修飾鎖の読み枠、+1..+8 の最長 C 連続）
   0 / 1 / 2 / 3 / 4 / 5 で呼び出し率 0.0635 / 0.0645 / 0.0944 / 0.1646 / 0.1949 / 0.3173 %。
   GC 十分位層別 CMH OR（C 連続 >= 3） = **2.560 [2.304, 2.845]**、p < 1e-300。
   **内部対照**: 同一枠・同一窓・同一 GC 含量の G 連続は 0.0635 / 0.0636 / 0.0622 / 0.0630 / 0.0765 / 0.0719 % と平坦
   （CMH OR 0.728 [0.626, 0.846]）。GC では説明できないことの直接証拠。
   多変量（GC・深度・遺伝子間・ホモポリマー・反復・交代 RY 同時）でも OR 2.295、p = 9.2e-50。
2. **cognate への近さ**（既知 AAGCCCG を固定。呼ばれた部位からモチーフを導出していない＝非循環）
   最小ハミング距離 <= 1: 5.23 % 対 2.03 %、CMH OR 2.170 [1.732, 2.719]、p = 5.0e-12。
   21 の単一ミスマッチ変異体のうち有意なのは **AACCCCG（3 位 G→C）だけ**で 17/2,114 = 0.804 %
   （背景 0.0635 % の 12.7 倍、他の単一ミスマッチ文脈に対する OR 6.02、BH q = 9.4e-7）。
   これは CCC を CCCC に延長する置換で、上の C 連続の結果と同じ現象を別の切り口で見ている。
3. **5' 塩基規則の保存**: 3' C 連続 >= 3 の中で 5'A 0.473 % / 5'C 0.191 % / 5'G 0.0749 % / 5'T 0.0623 %。
   H 対 G の CMH OR **3.407 [2.748, 4.223]**、p < 1e-300（cognate の粗比 5.51 に対しここでは 3.07）。

### 否定された（事前の予測どおり残す）
- **B3（最も見込みがあるとされた仮説）は陰性**。3 時点再現 903 部位と一過性 628 部位は、
  遺伝子間・ホモポリマー・G4・GC のどれでも区別できない（BH q >= 0.18、GC 調整 MH OR も同等）。
  違うのは**事前に交絡として宣言した量だけ**: レベル 0.5966 対 0.5277、深度 131 対 112、Nvalid 92 対 79。
  58.98 % という再現率は「閾値 0.5 からどれだけ上にあるか」の関数であって、二つのクラスの証拠ではない。
- **B1 は陰性**。convergent 間隙への見かけの偏り（粗 OR 2.215、p = 1.7e-7）は
  GC・深度・間隙長を入れると消える（OR 0.936、p = 0.657）。残るのは divergent 間隙の**枯渇**
  （OR 0.559、p = 8.3e-4）で、これは既知のプロモーター枯渇と同方向。終結・R-loop の予測は支持されない。
- **B2 は陰性**。G4 モチーフの濃縮（粗 OR 4.96）はホモポリマー項を入れると消える（OR 1.15、p = 0.43）。
  G4Hunter スコアの GC 層別差は +0.0026 [-0.0183, +0.0248] で 0 を含む。
  Z-DNA 代理（交代プリン–ピリミジン連長）は -0.372 [-0.449, -0.299] と**予測と逆符号**。
- **B4 は統制後に消失**。部位を持つ遺伝子の T1 TPM 中央値 6.69 対 9.76（MWU p = 1.7e-7）、
  部位密度と log TPM の生 Spearman r = -0.0573（p = 3.7e-7）。
  遺伝子 GC・oriC 距離・局所遺伝子密度・遺伝子長を統制した偏 Spearman r = **-0.0137、p = 0.225**。
  **これは中心命題（メチル化は転写を指令しない）の再確認であって新発見ではない。**
- プロモーター枯渇（13.52 % 対 18.18 %）は GC 十分位層別で CMH OR 0.988、p = 0.875 となり、
  局所 GC で完全に説明がつく。

### GC 統制後も残るが説明がつかないもの（既報の再確認）

## 原稿での扱い（判断は著者。根拠だけ並べる）

**本文に入れる価値があると考える材料（1 件）**
- 3' C 連続の用量反応と、同一 GC の G 連続が平坦という内部対照。
  これは「未帰属 6mA はゲノム全体に散らばる説明不能な背景」という現在の書き方を
  「cognate 認識配列の近縁文脈に沿った裾」に置き換えられる。
  ただし**酵素説と塩基呼び出し説の両義性を同じ段落に書くことが必須**で、
  書けないなら本文に入れるべきではない。正典の既存 caveat
  （非メチル化対照が無い／内部対照はゲノム全体の約 241 万アデニン）と直結する。

**補足に留めるもの**
- 単一ミスマッチ 21 変異体の占有率表（AACCCCG 0.804 % が唯一の有意）。
- 5' 塩基規則の保存（H 対 G、CMH OR 3.407）。cognate の 5' 規則の独立した傍証になるが、
  同じ k-mer 族を学習したモデルでも同じ結果になりうる。
- B3 の陰性（再現 59 % は閾値近接の関数であってクラスではない）。
  これは「再現する 59 %」を生物学的な部分集合として語らないための根拠なので、
  補足に残す価値がある。

**載せないもの**
- B1（間隙の向き）、B2（G4・Z-DNA）、B4（発現）。すべて統制後に消えるか符号が逆。
- 「convergent 間隙に偏る＝転写終結と関係する」という読み。GC で説明がつく。
- 近縁文脈を「緩和された特異性」「二次標的」と呼ぶこと。占有率が cognate の 57 分の 1 で、
  レベルも閾値直上に集中しており、その語に耐えない。

# 未帰属 6mA の生物学的意味 — 予測と判定規則（測定前に確定）

記入日時: 2026-10-16（測定開始前）。この文書は測定後に書き換えない。

## 共通の設計
- 対象: T1 プール（1-1,1-2,1-3）で refok（+鎖 A / −鎖 T）かつ pre-filter 深度 >= 30、
  Nvalid > 0、AAGCCCG の A0/A1（両鎖 2,660 位置）を除いた非モチーフ参照アデニン。
  呼ばれた = pooled Nmod/Nvalid >= 0.5。T1 で 1,531 部位、呼ばれなかった適格位置 2,412,520。
- 分母は常に「同じ深度条件を満たしながら呼ばれなかった適格アデニン」。ランダム対照は使わない。
- すべての 2x2 は Fisher 両側。連続量は Mann–Whitney。GC 統制は局所 GC（±25 bp, 51 bp 窓）の
  十分位層別 Mantel–Haenszel OR、または gc50 と log10(深度) を共変量に入れたロジスティック回帰。
- 多重比較: 仮説群ごとに検定数を数え Benjamini–Hochberg。各群の検定数は台帳に明記する。

## B3 再現集合と一過性集合は別物か（最初に測る）
- 定義: T1 で呼ばれた 1,531 部位のうち、T2 プールでも T3 プールでも同じ (pos, strand) が
  適格かつ呼ばれた = 再現部位。T1 のみ = 一過性部位。
- 予測 P3a: 再現部位では遺伝子間 OR・ホモポリマー OR・GC 中央値が一過性部位より強い。
- 判定 P3a: 再現 vs 一過性の直接比較（共通の分母ではなく互いを比較）で、
  intergenic または homopolymer の OR >= 1.5 かつ BH q < 0.05 なら支持。
- **交絡の事前宣言**: 再現性は T1 レベルと深度の関数でもある（閾値 0.5 直上の部位は T2 で落ちやすい）。
  したがって P3a が陽性でも、T1 レベル五分位で層別した MH OR と、
  lvl・log10(深度) を共変量に入れたロジスティック回帰で符号と大きさが保たれなければ支持としない。
- 予測 P3b: 再現部位のレベル分布は一過性部位より高い（これは交絡の確認であって発見ではない）。
- 予測 P3c: 再現部位が真の生物学的クラスなら、その配列文脈は一過性部位より収束する
  （最頻 9-mer の占有率が上がる）。判定: 再現集合の最頻 9-mer 率が一過性集合の 2 倍以上かつ
  GC 整合シャッフル背景の 95 パーセンタイルを超えること。

## B1 遺伝子間に集まるのは遺伝子間の種類による
- 定義: GFF の gene フィーチャから隣接遺伝子対の間隙を構築し、
  convergent（>  <）/ divergent（<  >）/ tandem（>  > または <  <）に分類。
  部位は間隙内にあるものだけを対象（CDS 内・遺伝子重複部は除外）。
- 予測 P1a: convergent 間隙に偏る → 転写終結・R-loop 絡み。
  divergent 間隙に偏る → 双方向プロモーター間領域。
- 判定 P1a: 3 カテゴリの chi2（呼ばれた vs 呼ばれなかった、間隙内のみ）で p < 0.05、
  かつ GC 十分位層別 MH OR >= 1.5（BH q < 0.05）のカテゴリが存在すれば支持。
  GC 統制後に消えるなら否定。検定数 = 3 カテゴリ + 全体 chi2 = 4。
- 予測 P1b: 呼ばれた部位を含む間隙は、含まない間隙より長い（長い間隙ほど非コード DNA が多い）。
  判定: 間隙長の Mann–Whitney p < 0.05。ただしこれは自明な長さ効果なので、
  単位長あたりの部位密度（部位数 / 適格アデニン数）で比較して初めて意味を持つ。
- 予測 P1c: 隣接遺伝子の発現量・機能分類に偏りがある。
  判定: 隣接遺伝子 TPM の Mann–Whitney と、COG/product 語のハイパー幾何検定（BH）。

## B2 ホモポリマーに集まるのは DNA の物理的性質
- 予測 P2a（最初に測る）: G 四重鎖モチーフ（G{3,}N{1,7} を 4 回）との重なりが
  呼ばれた部位で高い。判定: GC 十分位層別 MH OR >= 1.5 かつ q < 0.05。
- 予測 P2b: G4Hunter スコア（±25 bp, 51 bp 窓の平均。G 連長 1/2/3/>=4 に +1/+2/+3/+4、
  C 連長に同符号の負値、A/T は 0）が呼ばれた部位で高い。
  判定: GC 十分位層別の重み付き差が 0 を含まない（ブートストラップ 95% CI）。
- 予測 P2c: 交代プリン–ピリミジン連（Z-DNA 形成傾向の代理。GC/CG/GT/TG/AC/CA の交代長）が
  呼ばれた部位で長い。判定: GC 層別の重み付き差が 0 を含まない。
- 事前宣言: 構造パラメータの経験表（プロペラツイスト、副溝幅、最近接 ΔG）は、
  リポジトリに検証済みの表が無く記憶から数表を再構成するのは不可なので**使わない**。
  アルゴリズムとして定義できる指標（G4Hunter、連長、交代長）に限る。これは範囲の縮小として報告する。
- 事前宣言: 本件の対抗仮説は「ナノポア塩基呼び出しの k-mer 依存誤り」。
  G/C 連続への偏り（G 27・C 22 対 A 0・T 1）は enzyme 仮説と artefact 仮説の両方と整合する。
  P2a-c のいずれかが陽性でも、それは「配列文脈依存の呼び出し挙動」と区別できない。
  区別できない旨を必ず書く。

## B4 発現との関係
- 予測 P4: 未帰属 6mA を持つ遺伝子の発現が、持たない遺伝子と異なる。
- 判定 P4: 遺伝子単位の Mann–Whitney（log TPM）で p < 0.05。
  陽性なら oriC 距離・遺伝子 GC・局所遺伝子密度を統制した偏 Spearman まで必ず行う。
  統制後に |r| < 0.05 または p > 0.05 になるなら、**中心命題（許容的）の再確認であって新発見ではない**
  と書く。検定数 = 粗 1 + 偏 1 = 2。

## 事前に宣言する否定の受け入れ
上記のどれも GC 統制後に残らない場合、結論は
「GC リッチな遺伝子間 DNA に偏った、部分的に再現性のある背景である」に留める。
陰性を発見に膨らませない。

### B5 未帰属部位は酵素自身の標的 AAGCCCG の近縁文脈である
- 根拠: 真の 6mA 認識配列 HAAGCCCG は修飾 A の 3' 側に CCC を持つ。
  読み枠で C 連続に偏るという観測は、「認識配列の不完全一致文脈」で説明がつく。
- 予測 P5: 呼ばれた部位の AAGCCCG に対する最小ハミング距離が、呼ばれなかった適格部位より小さい。
- 定義: 各適格アデニンについて、修飾鎖の読み枠で A を A0 の位置に置いた登録と
  A1 の位置に置いた登録の 2 通りで 7-mer を AAGCCCG と比較し、小さい方のハミング距離を取る。
  **モチーフは既知の cognate 配列で固定。呼ばれた部位からは一切導出しない（循環の回避）。**
- 判定 P5: 「距離 <= 2」の GC 十分位層別 CMH OR >= 1.5 かつ p < 0.05/4（この群の検定数 4:
  距離 <=1, <=2, <=3 の 3 つと距離中央値の Mann–Whitney）なら支持。
  層別後に OR が 1 に戻るなら否定。
- **事前宣言（重要）**: P5 が陽性でも、それは (i) 酵素が近縁配列も弱く修飾している、
  (ii) ナノポア塩基呼び出しモデルが認識配列に似た k-mer で偽陽性を出す、の**どちらとも整合する**。
  本データだけでは区別できない。区別には非メチル化対照（WGA/PCR）か酵素破壊株が要る。
  陽性の場合はこの両義性を結論に必ず書く。

### B6 5' 塩基の規則が近縁文脈にも及ぶか（B5 陽性を受けて、測定前に追記）
- 背景（正典）: cognate では 5' 隣接塩基が規則を決める。HAAGCCCG 占有率 45.84/47.79/46.02 % に対し
  GAAGCCCG は 8.32/10.40/10.92 % で、5' の G が A0 の修飾を塞ぐ。
- 予測 P6: 未帰属部位が酵素の産物（緩和された特異性）なら、3' C 連続 >= 3 の文脈の中でも
  5' 隣接が H（A/C/T）の方が G より呼び出し率が高いはずで、比は cognate の約 5.5 倍に準じる。
- 判定 P6: 3' C 連続 >= 3 の適格アデニンを 5' 隣接塩基で層別し、H 対 G の呼び出し率比を取る。
  GC 十分位層別 CMH OR >= 2 かつ p < 0.05 なら「酵素規則が及ぶ」= 酵素説を支持。
  比が 1 付近（CMH OR の 95 % CI が 1 を含む、または < 1.5）なら、酵素規則は及ばず、
  塩基呼び出しの k-mer 挙動の説明が相対的に強くなる。
- 事前宣言: どちらの結果でも決定的ではない。酵素説を支持する場合でも、
  ナノポアモデルは cognate 文脈で学習されているので同じ 5' 規則を学習している可能性があり、
  非メチル化対照なしでは分離できない。この限界は結論に必ず書く。

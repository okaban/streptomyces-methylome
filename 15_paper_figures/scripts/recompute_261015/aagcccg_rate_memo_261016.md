# なぜ AAGCCCG の 6mA 修飾率は低いのか — 2026-10-16 再計算

対象の問い: 同一インスタンス上で 4mC が 67–76 % なのに、6mA（A₀）が 25 % 前後にとどまるのはなぜか。
予測と判定規則は測定前に `aagcccg261016/PREDICTIONS_REGISTERED_261016.txt` に登録した。
台帳は `aagcccg_rate_hypotheses_261016.tsv`。全数値はこのセッションで 9 ライブラリから再計算した。

## 結論

**認識配列が HAAGCCCG より長い。** 低い修飾率は酵素の性質でも検出感度でもなく、
**分母の定義**の問題である。配列を 5′ 側に延ばすと占有率は単調に上がり、4mC と並ぶ。

| 定義 | 部位数 | 6mA 占有率 T1 / T2 / T3 (%) |
|---|---|---|
| AAGCCCG（全インスタンス） | 1,330 | 24.66 / 27.70 / 26.30 |
| HAAGCCCG（正典の標的） | 561 | 46.52 / 50.09 / 47.69 |
| + offset −3 が G | 246 | 64.63 / 69.76 / 69.23 |
| + offset −5 が C かつ −3 が G | 85 | **75.29 / 80.00 / 78.82** |
| （参照）同一インスタンスの 4mC（C₄） | 1,330 | 67.07 / 63.51 / 62.51 |
| （参照）同一インスタンスの 4mC、H 部分集合 | 561 | 75.94 / 70.16 / 70.28 |

最もよく一致する文脈では 6mA 占有率 75.3–80.0 % で、**同じ部位の 4mC（70.3–75.9 %）と区別できない**。
深度 30 リード以上の部位、`--no-filtering` のリードレベルコールで算出（出典
`aagcccg261016/ladder_allread_261016.tsv`）。

## 測ったこと

**決定基の検出（循環を避けた形）。** 565 の HAAGCCCG インスタンスという配列で固定した集合の中だけで、
修飾された instance と されなかった instance の塩基組成を比較した。モチーフ外 20 位置 × 4 塩基 =
**1 時点あたり 80 回の Fisher 検定**、時点内で BH 補正、3 時点すべてで生き残ることを要求（登録済み規則）。
判定はこの登録規則のみで行い、二次走査は補助に留める。
生き残った offset は **−5(C) と −3（G が濃縮・A が枯渇）の 2 位置**
（−5C の q = 2.6e-06 / 1.7e-03 / 2.1e-02、−3G の q = 2.8e-12 / 3.8e-15 / 4.8e-16）。

**2026-10-16 訂正**: 初版はここに −6(A) と −4(C) も挙げていたが、登録規則では通っていない
（−6A の q = 0.2511 / 0.2620 / 0.0488 で T3 のみ、−4C の q = 0.0767 / 0.0286 / 0.0889 で T2 のみ）。
この 2 位置が 3 時点とも通るのは、より緩い二次走査（all-read レベル、offset ごとに最良塩基を選び
1 時点あたり 31 検定、最良塩基の選択を補正に課していない）でのみである。その走査では offset +15 と
+17 も通り、+15 は時点間で塩基が入れ替わる（T1 G / T2 C / T3 G）。したがって二次走査は
**示唆的な所見としてのみ**扱い、−6 と −4 を決定基として主張しない。
**占有率ラダーはこの訂正の影響を受けない**: ラダーは −3=G と −5=C だけで作っており、どちらも登録規則を通る。
局所 GC（101 bp）と log 深度を同時に入れたロジスティック回帰でも −3=G は独立に残る:
log-odds **+2.147 / +2.676 / +2.831**（−3=A 比の OR 8.6 / 14.5 / 17.0）、p = 7.2e-11 / 4.7e-15 / 1.4e-15。
−5=C は +0.694 / +0.909 / +0.957（p = 0.0185 / 0.0028 / 0.0017）。
**過学習ではない**: 部位を無作為に半分ずつ 20 回分割した外部評価で AUC 0.776 [0.748–0.823]、
局所 GC のみの 0.698 [0.664–0.724] を上回る。

**ナノポア k-mer 人工物の排除（3 本の対照）。**
1. 非標的 GAAGCCCG（769 部位）では −3 効果が存在しない（−3=G 10.1 % 対 −3=A 9.0 %、OR 1.13、p = 0.748）。
   塩基呼び出しの k-mer バイアスなら同じモチーフのこの集合にも出るはずである。
2. ゲノム全体の非モチーフアデニン（241 万箇所）の偽陽性レベルは −3=G 5.20 %、−3=A 3.45 %。
   これを加算モデル（測定レベル = f + (1−f)·ε）で伝播させると、観測された 14.23 pp のレベル差のうち
   **1.16 pp（8.1 %）** しか説明しない。
3. 同一インスタンスの 4mC（C₄）チャネルは順序が違う（A 59.8 < G 76.8 < C 80.7 < T 87.2 %）。
   −3=A の低下は両方の標識に共通（局所組成の効果）だが、**G の優位は 6mA に固有**である。
4. 深度 100 リード以上の 366 部位に限っても効果は残る（OR 5.60、p = 1.8e-07）。反復配列でもない
   （−6..−1 の最頻六量体は 261 例中 7 例 = 2.7 %）。

**残る留保**: 偽陽性チャネルは上のように上限を置けるが、**偽陰性（感度）チャネルは完全メチル化対照が
無いので上限を置けない**。ただし −3 塩基別に見た「修飾された部位の中でのレベル」は 0.591–0.646 と
ほぼ同じで、差は「どの部位が修飾されるか」に出ている。感度差が主因なら逆のパターンになる。

## 否定された仮説（否定のまま残す）

- **H1b 二峰性** — 部位レベルのレベル分布は 3 時点とも単峰（Hartigan dip p = 0.55 / 0.86 / 0.89）。
  占有率が低く見えるのは、0.5 の閾値が連続分布の中央付近（中央値 ≈ 0.48）を切っているためでもある。
- **H2 ヘミメチル化・複製後の遅れ** — AAGCCCG の相補配列 CGGGCTT は重ならないので、両鎖に文脈を持つ
  二本鎖が **0 本**。構造的に検定できない。oriC 距離は符号こそ予測どおりだが有意でない
  （p = 0.26 / 0.11 / 0.07、深度・局所 GC 統制後）。
- **H3 4mC による立体干渉** — 部位レベルの連関は **正**（OR +1.388 / +1.463 / +1.208）。予測と逆。
- **H4 酵素量律速** — SC_RS17645 の TPM は 9.95 → 1.55 → 5.47 と 6.4 倍動くのに、占有率は
  46.52 → 50.09 → 47.69 % でほぼ動かない。**2 つの遷移とも符号が逆**。酵素は律速ではなく過剰にある。
  4mC 側の酵素は未同定なので相対発現の比較はできない。
- **H5 細胞集団の二状態性** — 分子あたりの修飾数は過分散だが小さい（分散比 1.08–1.18、登録閾値 1.5 未満）。
  3 インスタンスを覆う T1 の 3,015 リードで k = 0/1/2/3 が 494 / 1,088 / 1,040 / 393、二項期待
  404 / 1,157 / 1,103 / 351 に対しわずかに広いだけ。完全二状態なら k=0 に 51.2 %、k=3 に 48.8 % が
  集まるはずで、観測は 16.4 % / 13.0 %。相変異ではない。
- **H6 検出感度** — 無フィルタ 46.52 / 50.09 / 47.69 % 対 フィルタ済み 46.17 / 47.96 / 45.20 %。
  差は +0.4 / +2.1 / +2.5 pp にすぎない。4mC（TGGCCGGC）の +5.1 pp 占有率・+15.5 pp レベルという
  正典のフィルタ偏りは、**6mA のこの位置にはほとんど効いていない**。
- **R1（二巡目）** — 5′ 延長は A₀ の修飾を支配するが、A₀→A₁ の位置の乗り換えは変えない
  （A₁ 占有率はラダー全体で 7.3–10.6 % と平坦）。

## 問い (b)「なぜ 6mA 側だけが 5′ 塩基で割れるのか」への答え

−1 位置は 6mA 酵素の認識位置（H）だが、同一インスタンスの 4mC 活性はそこを使っていない。
all-read で H 対 G の占有率比は 6mA が 5.34 / 4.43 / 4.47 倍、4mC は 1.25 / 1.20 / 1.24 倍。

**ただしブリーフにあった「背景が 3.00 倍あるので酵素に帰せるのは 1.85 倍」という割り算は使えない。**
背景の 3.00 倍は検出ノイズ床どうしの比（0.0909 % 対 0.0304 %、再計算値 2.99 でブリーフと一致）であり、
倍率のまま 48 % の信号に伝播しない。加算モデルで伝播させると、背景チャネルは観測された 16.64 pp の
レベル差のうち **0.44 pp（2.7 %）** しか説明しない。この割り算のどちらを採るかは、
文脈バイアスが「一定の偽陽性床」なのか「真の信号に比例する倍率」なのかの前提の違いである。
偽陽性床は定義上前者なので、加算モデルの方が擁護しやすい。**両方の数値を併記すること。**

## 原稿に入れる価値の仕分け

### 本文に入れる価値がある
- **HAAGCCCG は認識配列の全体ではない。** 5′ 側 offset −5 と −3 に決定基があり、−3 の G が最も強い
  （OR 8.6–17.0、局所 GC と深度の統制後、3 時点で独立に再現、外部評価 AUC 0.776）。
- **最もよく一致する文脈（−5=C, −3=G, 85 部位）では 6mA 占有率が 75.3–80.0 % で 4mC と並ぶ。**
  「6mA の修飾率が低い」という観察は、酵素の性質ではなく分母の取り方に由来する。
- これは 4mC 側の正典所見（TGGCCGGC は 8 bp で閉じず、+9 位置だけで 16.4 pp を張る）と**同じ形**で、
  両モチーフとも報告された長さより長いという対称的な訂正になる。

### 正典との衝突（判断は著者・査読側に委ねる。本エージェントは決めない）
- 正典項目「6mA recognition is GRADED（HAAGCCCG 45.8 % occupancy, does not saturate in the
  minimal-motif ladder）; 4mC recognition is BINARY ... This contrast is the paper's positive axis
  (user approved 2026-10-04)」。**ラダーが飽和しなかったのは 5′ 側を走査していなかったためで、
  延ばすと 4mC と同水準まで上がる。** 「graded 対 binary」をこの軸で主張する根拠は弱くなる。
  なお別の正典項目は 2026-10-05 に「binary vs graded」を主軸としては既に撤回しており、
  正典内部にこの時点で矛盾がある。
- H3 の部位レベル OR: 正典は「site level OR 1.04, p 0.81」。参照塩基照合後の 1,330 測定可能
  インスタンスでの再計算は **1.388（p = 0.0406）**。符号はどちらも正なので H3 の否定は変わらないが、
  正典値は再現しない。

### 補足に留めるもの
- 否定された H2・H3・H4・H5・H6 の一式（上表）。とくに **H6 は方法論として価値がある**:
  modkit のフィルタ偏りは 4mC では大きい（+15.5 pp）が 6mA のこの位置では +0.4〜+2.5 pp しかない、
  という標識依存性は正典の方法論所見を補強する。
- 局所 GC（101 bp 窓）が部位レベル占有率の強い独立予測因子であること
  （係数 +15.46 / +16.27 / +13.53、p ≈ 1e-11）。交絡として統制済みだが、それ自体の解釈は未決。

### 載せないもの
- 「背景 3.00 倍を割り引いて酵素寄与は 1.85 倍」という計算。上記のとおり伝播モデルが成立しない。
- 延長した認識配列を「新規モチーフ」として提示すること。決定基の検出であって、F1 最大化による
  モチーフ定義の正典規則を通していない。正典規則で引き直すか、「決定基」として書くかのどちらか。
- 相変異・ヘミメチル化・立体干渉のいずれも、本データでは支持がない。
